# dsh-agent-group v0.3.0

`0.3.0` moves the complete `0.2.0` Agent Workspace product surface to DeepSeek Harness `0.1.7-alpha.2`. It preserves the durable domain, definitions, colleagues, rooms, Tasks, unified Memory, Runtime activity, delegation rules, child runs, and the read-only forward exporter.

## Compatibility

This line supports DeepSeek Harness `>=0.1.7-alpha.2 <0.1.8-0`, verified at `0.1.7-alpha.2` commit `00102833dfaee1da9f48a3a8eae9d34005a75218`. DSH `>=0.1.1-rc.2 <0.1.2-0` remains supported by plugin `0.2.x`; one artifact does not attempt to load both client module architectures.

The Browser package uses the current DSH client store and module-table baseline instead of the removed `@deepseek-ai/dsh-client-runtime`. The Host adapts only to current public APIs; storage-domain version `0` and workspace record semantics remain unchanged.

## Verification

The candidate gate builds and typechecks against exact registry packages and the exact source commit, packs all three packages, installs those tarballs into a clean Web profile, and drives the Definitions, Tasks, Memory, and Runtime workflow through a real browser. Test scratch and profile homes are placed on an explicit E-drive root and removed after a successful run.

On 2026-10-08, the final package gate passed build, typecheck, client-copy validation, and 784 tests in 41 files. The packed Browser workflow passed on the verified DSH commit, including restart persistence and removal without deleting core sessions. Its local scripted provider exercises integration without calling a live model API; these results are not a live-provider quality evaluation. The final review also added disposal regressions for Web routes and failed employee-session recovery.

```sh
pnpm release:pack
pnpm smoke:packed -- --dsh E:/003code/deepseek-harness --scratch-root E:/003code/deepseek-harness-plugins/.tmp/dsh-agent-group-smoke
```

## Newer DSH releases

As checked on 2026-10-08, npm's DSH `latest` is `0.2.0-rc.2` and `alpha` is `0.2.1-alpha.1`. Both fall outside this release's peer range and DSH's compatibility evaluator rejects the Host and Web packages without an explicit exemption. This release does not claim runtime compatibility with either version. The next compatibility release needs updated dependency ranges and clean-profile Browser verification. DSH `0.2.1-alpha.1` also removes upstream runtime invariant plugins and their exports; the plugin's own workspace validation is separate and remains required.
